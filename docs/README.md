# 「あかし」プロジェクト ドキュメント引き継ぎメモ

アプリ「あかし - 冤罪防止・自衛の記録」に関する、App Store提出・法務文書のドラフトです。
いずれもプレースホルダーを含む**未確定のドラフト**であり、公開前に下記の対応が必要です。

## ファイル構成

- `app-store/metadata_draft.md` — App Store Connect 掲載文言(アプリ名・説明文・キーワード・審査担当者向けメモ等)
- `legal/privacy_policy_draft.md` — プライバシーポリシー
- `legal/terms_of_service_draft.md` — 利用規約
- `legal/tokushoho_draft.md` — 特定商取引法に基づく表記

## 公開前の未確定事項(横断まとめ)

各ファイル末尾にも個別のチェックリストがありますが、共通して埋める必要がある情報は以下の通りです。

- [ ] **事業者名・屋号**(プライバシーポリシー、利用規約、特商法表記で共通)
- [ ] **氏名(特商法表記)** — 個人事業の場合は戸籍上の氏名、または屋号+氏名の併記が必須(屋号のみは不可)
- [ ] **運営統括責任者名**(特商法表記)
- [ ] **問い合わせ用メールアドレス**(プライバシーポリシー・利用規約・特商法表記で共通、実際に稼働する窓口が必要)
- [ ] **管轄裁判所**(利用規約 第8条)
- [ ] **対応iOSバージョン**(特商法表記)
- [ ] **年齢制限の確定**(録音・位置情報・犯罪関連コンテンツを扱うため、App Store Age Ratingアンケートの結果を待って12+/17+を確定させ、プライバシーポリシー第5章にも反映)
- [ ] **クラウド同期機能の有無**(実装する場合、プライバシーポリシー第2章に保存方法を追記)
- [ ] **各文書の最終更新日**
- [ ] 実装済みアプリからのスクリーンショット撮影(モックアップ不可)
- [ ] アプリ名・キーワードの重複確認(App Store内検索)
- [ ] 特商法・プライバシーポリシー・利用規約は、可能であれば公開前に専門家(弁護士)レビューを推奨

## 次のアクション候補

上記の空欄が埋まり次第、これらのドラフトから "draft" を外した確定版を作成し、Webで公開(プライバシーポリシー・特商法表記はURLが必要)、App Store Connectへの入力を行う。
