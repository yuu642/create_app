「あかし」(以下「本アプリ」)は、[事業者名/屋号を記入](以下「当方」)が提供します。本ポリシーは、本アプリが取得する情報とその取り扱いについて説明するものです。

## 1. 取得する情報

本アプリは、以下の情報を取得することがあります。

| 情報の種類 | 取得するタイミング | 目的 |
|---|---|---|
| 音声データ | ユーザーが「記録開始」を操作した場合 | 状況の証拠として端末内に保存するため |
| 位置情報(GPS) | 記録開始時 | 記録の日時・場所を証拠として残すため |
| カメラ・写真へのアクセス | ユーザーが両手撮影・画面録画機能を使用した場合 | 証拠映像を作成するため |
| スマートフォンの操作ログ(直前に使用していたアプリ名など) | 「盗撮モード」使用時 | カメラ未使用の証明のため |
| 記録の保存データ(音声・映像・位置情報・タイムスタンプ) | 記録終了後 | 本人が後から確認・共有できるようにするため |
| 課金情報 | アプリ内購入時 | Apple社のIn-App Purchaseを通じて処理され、当方はカード情報等を直接取得しません |

## 2. 情報の保存方法

- 記録データは、原則として**ユーザーの端末内に暗号化して保存**されます。
- [クラウド同期機能を実装する場合はここに詳細を記載: 例「有料プランでクラウドバックアップを有効にした場合、暗号化した状態で当方のサーバーに保存されます」]

## 3. 第三者への提供

- 当方は、ユーザーの同意なく、記録データを第三者(警察・弁護士を含む)に提供することはありません。
- ユーザーが「警察・弁護士へ共有用に書き出す」機能を使用した場合に限り、ユーザー自身の操作によって第三者に共有されます。
- 法令に基づく開示請求があった場合は、関連法令に従って対応することがあります。

## 4. 録音に関する注意事項

- 本アプリは、ユーザー自身が当事者として関与する会話・状況の録音を目的としています。ユーザーは、本アプリの利用にあたり、録音に関する各都道府県・国の法令を遵守する責任を負います。
- 当方は、本アプリの記録データが法的な証拠として認められることを保証するものではありません。
