## 説明文(本文)

```
「あかし」は、痴漢や盗撮を疑われた瞬間の自衛をサポートするアプリです。

■ ワンタップで記録開始
録音・位置情報・時刻を自動で記録します。痴漢を疑われた場合は両手の位置、盗撮を疑われた場合はスマホの操作ログなど、状況に応じた証拠を残せます。

■ 対処法ガイド
「その場で示談に応じない」「安易に署名しない」など、疑われた直後にすべき行動を、弁護士監修のもとで分かりやすく案内します。

■ 弁護士への連絡
当番弁護士制度など、専門家への相談導線をワンタップで用意しています。

■ 基本機能はずっと無料
記録・アラーム・対処法ガイド・弁護士への連絡は、無料でご利用いただけます。着せ替えテーマやアラームボイスなど、任意の応援課金でお楽しみいただける機能もあります。

※本アプリは、記録データが法的な証拠として認められることを保証するものではありません。
※録音を行う際は、各地域の法令を遵守してご利用ください。
```
